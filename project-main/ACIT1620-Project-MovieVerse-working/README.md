# MovieVerse – Film Review Showcase

## Overview
This starter project is part of  ACIT 1620 – Fundamental Web Technologies.  
Build a multi-page film review website using semantic HTML and CSS transitions.

## File Structure
```
MovieVerse_Project/
├── index.html
├── reviews.html
├── contact.html
├── css/
│   └── style.css
└── images/
```
##Project Requirements
You will create a three-page website with the following structure and features:
1. Home Page (index.html)
• Featured movie banner with overlay text.
• Navigation links to all pages.
• Recent reviews section.
2. Reviews Page (reviews.html)
• Grid of review cards with poster, rating, and summary.
• CSS transitions for hover effects.
3. Contact Page (contact.html)
• Reviewer contact form and social links footer.

##Project Objectives
- Apply semantic HTML5 elements to organize webpage content.
- Use external CSS to control layout, colors, and typography.
- Implement responsive design techniques using Flexbox, Grid, and media queries.
- Demonstrate consistent design patterns and accessibility standards.
- Follow proper file organization and indentation conventions.
- Use of Flexbox for review card layout.
- CSS animations and transitions (hover zoom, fade-in).
- Consistent theme and color palette.
- Accessibility through semantic markup.

## Setup
1. Extract the ZIP file.
2. Open in VS Code.
3. Edit HTML and CSS to customize your content.
4. Add movie posters and visuals.
5. Test responsiveness on different devices.
